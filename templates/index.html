ℹ️ About FreshGuard

FreshGuard is a Deep Learning based food freshness detection system developed as a student PBL project. It uses trained MobileNetV2 models to visually classify multiple fruit types and vegetable types according to their freshness conditions.

⚠️ Important Note

This system performs visual image-based freshness detection. Results are predictions from a trained model and should not be treated as a guarantee of food safety.
